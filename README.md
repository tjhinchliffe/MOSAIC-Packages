# MOSAIC Packages

Public catalogue and release assets for optional MOSAIC packages.

## Available packages

- **NAPLAN Network** — optional privacy-preserving analysis across school
  contribution workbooks. Requires MOSAIC 2026.0.7 or later and is not included
  in the base MOSAIC Windows or macOS download.
- **PAT Reading Adaptive** — optional PAT Reading reporting and planning tools.

`packages.json` is the catalogue consumed by MOSAIC. Package ZIP files are
published as GitHub Release assets and verified against the catalogue SHA-256
checksum before installation.
